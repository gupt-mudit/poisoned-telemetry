Audit & forensics

Every step is written to a sealed logbook. Each entry carries a fingerprint of the one before it, so changing any line breaks the chain, like a broken seal. Verify checks the seal with an independent program (tools/verify_audit.py). Tamper test secretly changes one decision in a copy, and the check catches it.

A hash chain proves the record was not changed after it was written. It does not prove the record is true.
