# Policy gap register

Each gap is a precise question that an existing framework may not explicitly resolve when an
AI agent is manipulated through the data it reads. Every row names the closest existing
provision and what it already covers, so we never claim "no rule exists".

**Status legend:** `TO_VERIFY` = Person A must check the article against the official text
before submission. Nothing marked `TO_VERIFY` may appear in the final report as a citation.

**Wording rule:** write "existing frameworks may not explicitly resolve…", then show why.

## How to complete this register
1. Person A replaces each `TO_VERIFY` with the exact article after reading the official text.
2. If a provision turns out to resolve the question, **delete or narrow the gap** — that is a finding too.
3. Keep "Exposed by" accurate: link each gap to the scenario or experiment run that showed it.
